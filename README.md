# Subhasish Rath — Portfolio

A premium, modern developer portfolio built with Next.js (App Router), TypeScript, Tailwind CSS, Framer Motion, and Lenis smooth scroll.

## Tech Stack

- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Framer Motion** (animations)
- **Lenis** (smooth scroll)
- **Lucide Icons**
- **ShadCN-style UI** (Button, Input, Textarea)

## Design

- Dark futuristic theme with purple/indigo accents
- Glassmorphism cards and UI
- Parallax backgrounds and floating blobs
- Subtle micro-interactions and scroll-based animations
- Responsive, 8px grid, 2xl rounded corners

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### GitHub Activity (Private + Public)

To include private contributions in the GitHub activity card, add a GitHub token:

```bash
GITHUB_TOKEN=your_github_token_here
```

Use a token that can read your contribution graph. Private contributions are available for the token owner's account (if private contribution display is enabled on GitHub).

## Build

```bash
npm run build
npm start
```

## Structure

- `app/` — Layout, page, metadata
- `components/` — Header, SmoothScroll, UI primitives
- `sections/` — Hero, About, Projects, Skills, Contact
- `lib/` — utils (cn)
- `styles/` — globals.css
